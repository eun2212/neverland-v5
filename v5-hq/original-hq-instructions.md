# v5 작업 본부

이 폴더는 네버랜드 게임의 v5 작업 본부(HQ)다. 게임의 통합본은 `neverland-v4/`에 있다.

- 사용자의 새 작업 요청은 주제별로 별도 Codex 스레드에서 진행하고, 이 대화는 HQ로 사용한다. 별도 스레드는 이 프로젝트에 연결한다.
- 작업별 요청, 결정, 결과와 통합 상태를 `threads/`의 개별 파일에 기록한다. 대화 자체의 저장 위치는 Codex가 관리하므로 파일 기록은 그 내용을 대신하는 작업 기록이다.
- 선택이 필요한 내용은 해당 작업 스레드에서 정하고, 선택된 결과를 HQ에서 게임 통합본에 반영한다. 선택이 아직 확정되지 않았다면 확정된 것처럼 적용하지 않는다.
- 매 작업마다 `v5 · 요청 일치 검증` 스레드에서 결과가 사용자의 요청에 맞는지 독립적으로 검증하고, 발견한 문제를 해결한 뒤 HQ에서 통합한다.
- 통합 후 적절히 확인하고, 게임을 사용자가 볼 수 있도록 앱 내 브라우저에 연다. 로컬 미리보기는 이 폴더의 `preview-server.cjs`를 사용할 수 있다.
- 사용자가 별도로 지정한 경로나 지시가 있으면 그 지시를 따른다. 기존 파일과 다른 작업의 변경을 보존한다.
