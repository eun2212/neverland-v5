# v5 최신 인수인계 · 2026-11-21

현재 저장소는 `eun2212/neverland-v5`이며 `index.html`이 최신 통합본입니다. 다른 컴퓨터에서는 README의 clone 및 `node server.cjs` 지침을 사용하세요. 아래의 v2 기록은 과거 이력으로, URL·기구명·검증 수치·배포 상태가 현재와 다를 수 있습니다.

- 선택된 기구명: 후크의 마지막 항해, 네버랜드로의 비행, 잃어버린 아이들의 회전목마, 인어의 석호 거울, 팅커벨의 티파티, 두 번째 별 너머. 영문 간판과 한국어 안내를 일치시켰으며 기존 게임 ID·저장 형식은 유지합니다.
- 캡틴 훅 기구의 가로 레버, 기구별 키퍼 강제 개입, 롤러코스터 안전바와 남녀 탑승자, 별 잇기·태엽·차 따르기 미니게임이 통합되어 있습니다. 거울 미로는 기존 탐색 방식입니다.
- `game-tools.js`의 제작 메뉴는 이야기·기구·부스·엔딩을 세밀하게 나눕니다. 제작 테스트는 수집과 수동 저장을 격리합니다. 실제 브라우저의 WebGL 및 장면을 확인하세요.
- 이 저장소의 `v5-hq/threads/`는 작업 기록, `v5-hq/assets-v5/`는 원래 HQ에서 보존하던 이미지 자료입니다. Codex 스레드 자체는 Git 저장 대상이 아닙니다.
- 미리보기 서버가 꺼지면 이미지가 비어 보일 수 있습니다. `node server.cjs`를 실행하고 현재 탭을 다시 여세요. 기존 플레이 진행은 브라우저 로컬 저장소에 있으며 Git으로 자동 이전되지 않습니다.
- 현재 코드는 자동 검사 외에 전체 3D 플레이를 모든 브라우저에서 끝까지 검증한 상태는 아닙니다. `prepare-full-story.cjs`를 실행하지 마세요.
