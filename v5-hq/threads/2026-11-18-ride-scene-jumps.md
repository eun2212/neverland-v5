# 놀이기구 장면 이동

- 요청: 기존 제작용 장면 이동에서 모든 이용 가능한 놀이기구를 바로 조작하거나 탈 수 있도록 연결하고 기존 테스트·저장 보호를 유지한다.
- 조사: 공원에 구현된 이용 가능한 기구는 캡틴 훅, 별의 관람차, 장미 회전목마, 거울 미로, 달빛 찻잔과 별바람 롤러코스터다. 성의 장식 그림에만 등장하는 자이로드롭은 실제 상호작용 기구가 아니다.
- 결과: 기존 첫 캡틴 훅 탑승/튜토리얼 경로를 유지하고, 관람차·회전목마·찻잔은 좌석에 앉은 조작 가능 상태로 이동한다. 거울 미로는 이동 가능한 출발점과 완료 처리 상태를 설정한다. 누락된 롤러코스터를 메뉴에 추가해 승강장 조작 화면을 연다. 기존 `prepare()`를 사용해 프로필을 유지하고 테스트 모드 및 수집·수동 저장 보호를 적용한다.
- 변경 파일: `neverland-v4/game-tools.js`, `neverland-v4/verify-game-tools.cjs`.
- 검증: `node neverland-v4/verify-game-tools.cjs` 통과 (604개 확인); `node neverland-v4/verify-manual-save.cjs` 통과 (579개 확인); `neverland-v4` 폴더에서 `node verify-coaster-lever.cjs` 통과. 롤러코스터 장면 이동 검증은 해당 모듈의 진입 호출을 모의 객체로 확인했고 실제 조작은 별도 레버 검증으로 확인했다.
- 통합 상태: 공유 게임 파일에 반영됨. 실제 브라우저에서 각 항목의 시각 상태 및 전체 흐름은 HQ 확인 필요.
