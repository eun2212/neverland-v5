# 롤러코스터 HQ 통합

- 요청: 오른쪽으로 당기는 2D 레버, 왼쪽 역방향 시 키퍼의 강제 개입, 360도 회전과 불꽃.
- 통합: 세 기어 체결 뒤 독립 레버 모듈이 열리며, 오른쪽 끝이나 역방향 강제 조작 뒤 열차가 출발한다. 취소하면 기어 화면으로 돌아간다. 360도 배럴 롤과 불꽃을 주행에 추가했다.
- 검증: JS 문법 검사 및 독립 레버 자동 검증 통과. 주행 스레드에서 관련 검증 구간 통과; 전체 검증은 기존 마스코트 테스트의 document 오류로 완료되지 못했다. 게임 시작 화면은 브라우저에서 열렸으나 실제 탑승의 시각 검증은 아직 필요하다.
- 후속 통합: 사용자가 제공한 두 참고 이미지를 `assets-v5/references/`에 보관했다. 손그림 STOP–GO 레일과 빨간 손잡이, 화면 위에서 내려와 함께 움직이는 별 문양 흰 장갑, 글리치를 반영하고 새 투명 손 에셋을 연결했다. 상태창이 크게 보이도록 게임 패널과 버튼 스타일을 조정했다.
- 후속 검증: 레버 단위 검증과 기어→레버→출발·취소·재입장 통합 검증 통과. 브라우저의 분리된 상태창 화면에서 레버와 역방향 손 개입을 시각 확인했다. 실제 게임 전체 탑승과 실제 터치 기기는 확인하지 않았다.
