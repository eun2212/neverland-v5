# 별바람 롤러코스터 연출 검토

- 요청: 현재 구현과 세계관을 확인하고 2D 레버, 반대 방향 조작 시 키퍼의 강제 개입, 360도 회전과 불꽃의 구현 유의점 및 검증 항목을 HQ에 보고한다.
- 상태: 검토 완료. 아래는 제안이며 선택과 게임 반영은 미확정이다. 코드는 수정하지 않았다.

## 현재 구현과 맥락

- `neverland-v4/coaster.js`에서 금빛·자주·민트 기어 세 개를 오른쪽 홈에 끌어 놓거나 Enter/Space로 체결하면 열차가 30초 동안 폐곡선 선로를 한 바퀴 돈다. 잘못 놓으면 안내만 표시한다. 레버, 손, 불꽃과 수직 360도 회전은 없다.
- CatmullRomCurve3 선로의 수평 접선으로 레일 좌우를 산출하고 차량은 접선을 향한다. 일반 카메라는 좌석에서 앞을 바라보며, 움직임 감소 시 외부 고정 시점이다. 도중 복귀가 가능하고 재입장 시 UI가 초기화된다.
- `story-3d.js`는 탑승 중 걷기를 막고 복귀 콜백으로 공원에 돌아간다. `manual-save.js`는 탑승 중 저장을 막는다. 이 독립 기구가 기존 첫 탑승 STOP–GO 레버 사고와 같은 장면이라는 근거는 확인되지 않았다.
- 별 장식과 붉은색·금색 선로, 녹색 구조물의 밤 놀이공원에 별빛을 곁들인 불꽃이 어울린다. 키퍼의 강제 개입은 위험을 조성하고 자신이 필요해지기를 바란 기존 인물상과 부합하지만, 의사 침범을 안전한 도움이나 동의로 묘사하면 이야기의 의미가 바뀐다.

## 구현 제안과 결정 사항

- 화면 고정 2D 조작판에 좌우 한계와 오른쪽 목적지를 표시한다. 포인터 시작점에서 왼쪽으로 일정 거리 이상 움직여야 잘못된 시도로 판정해 떨림을 배제한다. 손잡이가 처음부터 최좌측이면 왼쪽 시도를 감지할 여지가 없으므로 중립 위치나 여유가 필요하다. 기존 세 기어를 대체할지 추가 단계로 둘지는 결정 필요.
- 잘못된 시도에 흰 장갑과 녹색·금색 소매의 손이 화면 밖에서 나타나 레버에 닿은 뒤 오른쪽 끝까지 함께 밀고, 짧은 대사 또는 상태 문구로 강제 개입을 전달하는 방식을 제안한다. 키퍼의 등장 조건과 강제 이동 후 자동 출발 여부는 확정 필요. 키퍼의 부재나 관계 변화가 가능한 이야기 단계에 무조건 등장시키지 않도록 검토한다.
- 360도가 선로를 따라 뒤집히는 수직 루프인지, 객차의 종방향 회전인지 먼저 정해야 한다. 카메라만 회전시키면 선로·차량과 맞지 않는다. 수직 루프라면 선로 형상, 3D 레일 프레임, 차량 방향과 카메라 up 벡터를 함께 설계해야 한다. 수직 접선 부근에서 현재 수평 `right` 벡터가 불안정해지므로 연속 프레임과 폐곡선 접합부의 방향 연속성, 차량 간격과 지면·구조물 충돌을 검토한다.
- 루프 정점 또는 완주 직후 짧은 금빛·별빛 입자와 잔광을 제안한다. 레일 밖에 배치해 시야를 확보하고 화면 전체 섬광은 피한다. 입자 수와 수명에 상한을 두고 재입장·중도 이탈 시 정리한다.
- 움직임 감소 시 기존 외부 고정 시점을 유지하고 손과 불꽃을 정적인 상태 변화로 대체해 동일한 결과와 안내를 제공한다. 방향키와 Enter/Space로 동등하게 조작하고 왼쪽 시도도 가능하게 한다. `role=status`로 상태를 알리고 출발·복귀 시 포커스를 안전하게 이동한다.

## 검증 항목

1. 마우스·터치·키보드에서 오른쪽 성공, 왼쪽 시도, 미세 움직임, 포인터 취소·캡처 손실, 반복 입력과 중도 복귀를 확인한다. 강제 연출 중 입력과 출발이 중복되지 않아야 한다.
2. 손과 레버의 접점·방향·출발 시점, 대사와 상태 안내, 키퍼 등장 조건 및 이야기 단계의 일관성을 확인한다.
3. 선로 접합부와 수직 구간에서 레일 뒤틀림, 차량 간격, 시점 뒤집힘, 지면·구조물 관통을 확인한다. 정상 시점과 움직임 감소 시점을 각각 확인한다.
4. 불꽃이 UI와 경로를 가리지 않고 성능을 유지하며 반복 탑승·중도 복귀·새 게임에서 입자와 타이머가 남지 않는지 확인한다.
5. 작은 모바일 화면·확대·키보드 포커스·스크린리더 안내를 확인하고 저장 제한, 공원 복귀, 재입장 초기화와 다른 놀이기구 및 첫 탑승 흐름의 회귀를 점검한다.

검토는 소스 정적 확인에 기반하며 실제 플레이나 시각 검증은 수행하지 않았다.
