# 기구별 작동 미니게임 개선 · 2026-11-21

요청: 거울미로를 제외한 기구의 조작 화면을 간결하게 하고, 관람차 별 잇기·회전목마 태엽·찻잔 바퀴에서 거부 시 키퍼가 개입하도록 구현한다. 캡틴 훅과 롤러코스터의 기존 레버 동작은 보존한다.

구현: ride-interactions.js/.css와 3종 배경 및 조작 이미지 추가, story-core.js와 연결. 관람차는 순서대로 별을 잇고, 회전목마와 찻잔은 시계방향으로 돌린다. 거부·역방향·오랜 무조작 시 키퍼가 작동한다. 찻잔은 반사 손이 먼저 나타난다. 캡틴 훅·롤러코스터 레버 안내 중복 제거. 롤러코스터 기어 단계 제거 작업 중.

검증: 신규 컴포넌트 직접·거부·방치·역방향·취소·중복 실행 단위검사 통과. 기존 전체 스토리 및 레버 검증 통과. 게임 화면에서 관람차 직접 작동, 회전목마 역방향 개입, 찻잔 거부와 반사 연출 확인. 최종 통합 검증은 진행 중.

최종 통합: 롤러코스터 기어 조립을 제거하여 레버로 직행하도록 수정했고, 실제 게임에서 레버 표시와 출발을 확인했다. 오르골 소리를 사용자 조작에 연결했다. 새 미니게임·롤러코스터 진입·레버·장면 이동·캡틴 훅 관련 검사는 통과했다. 3D 전체 통합 자동 검사는 완료되지 않았으나 게임 창에서 관람차·회전목마·찻잔 장면을 확인했다. 일반 플레이 전체 경로와 터치 기기 검증은 수행하지 않았다.
