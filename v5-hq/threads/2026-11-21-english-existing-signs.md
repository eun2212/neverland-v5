# 기존 간판 영어 표기 · 2026-11-21

요청: 기존 간판 이름을 영어로 변경. 새 놀이기구 이름은 사용자 선택 전 확정하지 않는다.

결과: 음식점 실물 간판을 STARLIGHT DRINKS, MOONCLOUD CANDY로 변경했다. 미니게임 네 곳의 영문 이름은 유지했다. 장소 탐색 및 접근성에 쓰이는 한국어 이름과 게임 기능은 그대로다. 놀이기구의 새 명칭은 변경하지 않았다.

검증: node --check carnival-scene.js 및 node verify-midway-signs.cjs 통과. 게임 화면 직접 확인은 HQ에서 진행한다.
