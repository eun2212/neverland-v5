# 롤러코스터 기어·레버 통합 검증 — 2026-11-18

- 범위: 현재 coaster.js와 coaster-lever.js의 연결을 독립 검토. 게임 코드와 레버 파일은 변경하지 않음.
- 자동 검증: 프로젝트 루트에서 `node threads/verify-coaster-integration.cjs`. 실제 두 모듈을 VM의 경량 DOM과 가상 타이머에서 함께 실행한다. 기어 체결 후 레버 표시, End 키 출발, 퇴장 후 재입장 초기화, 강제 출발 대기 중 취소 및 타이머 정리, 다시 체결, 레버 표시 중 닫기와 재입장을 확인했고 통과했다.
- 레버 단위 검증: `cd neverland-v4; node verify-coaster-lever.cjs` 통과.
- 기존 `verify-carnival-scene.cjs`는 레버 통합 전 가정이다. 모듈 로드 목록에 coaster-lever.js가 없고, 세 번째 기어를 체결하자마자 출발한다고 가정하므로 갱신이 필요하다. 이번 검증에서는 이 파일을 수정하지 않았다.
- 한계: 별도 통합 검증은 DOM 모형을 사용하므로 실제 렌더링, 터치 좌표, 화면 배치 및 3D 차량 이동을 검증하지 않는다. 브라우저에서 포인터 조작과 시각적 흐름을 추가 확인해야 한다. 작업 중인 레버 화면 변경이 완료되면 재실행할 것.
- 통합 상태: 검증 스크립트만 추가. 게임 코드 수정 없음.
