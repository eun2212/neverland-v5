# v5 작업 기록

작업별로 별도 파일을 만들어 요청, 결정, 결과 및 HQ 통합 상태를 기록한다. Codex 스레드 자체는 앱에서 관리한다.

상설 스레드:

- 이미지: 이미지와 게임 에셋 구상 및 제작
- 아이디어: 스토리, 연출과 게임 기획
- 오류: 원인 조사, 수정 방안과 검증
- 게임 적합성 검토: 세계관, 분위기와 기존 게임 구조에 맞는지 확인
- 요청 일치 검증: 매 작업 결과가 사용자의 요청을 충족하는지 독립적으로 확인

새 역할이 필요하면 별도 스레드를 추가한다. 선택된 결과는 v5 HQ에서 게임에 통합한다.
