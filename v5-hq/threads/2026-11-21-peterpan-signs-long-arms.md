# 긴 키퍼 팔과 피터팬 놀이기구 간판 · 2026-11-21

요청: 롤러코스터에서 키퍼가 안전바를 내릴 때 팔이 잘리지 않도록 긴 이미지를 사용하고, 기존 간판을 영어로 통일. 놀이기구 간판은 후보 중 사용자가 고른 이름을 제작해 적용.

사용자 확정명: Hook's Last Voyage / Flight to Neverland / Lost Boys' Carousel / Mermaid Lagoon Mirrors / Tinker Bell's Tea Party / Beyond the Second Star.

구현: 6개 입구 간판에 항해·별빛·인어 테마의 새 이미지 3종과 선택된 글자를 적용, 음식점 간판을 STARLIGHT DRINKS / MOONCLOUD CANDY로 변경. 안전바에 긴 소매 이미지 keeper-safetybar-long-arms.png를 연결하고 손이 바와 함께 이동하며 소매는 화면 위에서 이어지도록 배치. 기존 한국어 안내와 조작 유지.

검증: 기구 간판·음식점 간판·안전바 조작 및 롤러코스터 진입 검사가 통과. 화면 조작 도구 연결 불능으로 실제 3D 간판 가독성·팔 배치의 시각 검증은 미완료. 독립 검증 진행 중.

독립 검증에서 좁고 높은 화면에서 소매 상단이 보일 수 있는 위험을 발견해 팔 이미지의 최소 높이를 장면 높이의 110%로 보정했다. 안전바의 끝 위치에서도 이미지 상단이 화면 밖에 있도록 설계했다. 자동 검사는 재통과했으나 실제 시각 확인은 도구 연결 문제로 수행하지 못했다.
