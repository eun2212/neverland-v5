# 키퍼의 롤러코스터 레버 이미지

- 요청: 키퍼의 손이 화면을 크게 채우며 롤러코스터 레버를 억지로 오른쪽으로 미는 장면 제작. 게임 코드는 수정하지 않음.
- 결과: `assets-v5/keeper-coaster-lever/keeper-coaster-lever.png` (PNG, 1672×941, 가로형). 흰 장갑, 아이보리 프릴, 금 별 장식의 짙은 초록 소매와 붉은 손잡이를 사용한 완성형 배경 CG.
- 근거: `neverland-v4/KEEPER-ART-V3.md` 및 기존 `design-candidates/keeper-standing-v2/01-basic.png`의 키퍼 의상과 그림체를 참고했다. 이미지 생성으로 제작했으며, 손과 레버는 분리된 투명 레이어가 아니다.
- 결정 상태: 시안. 사용자가 언급한 참고 이미지가 전달되지 않아 그 이미지와의 일치는 미확정이며 최종 선택도 미확정이다.
- HQ 통합 제안: 선택 후 이미지를 게임 에셋 폴더로 복사하고 해당 롤러코스터 장면에서 전체 화면 컷인으로 표시한다. `object-fit: cover` 사용 시 화면비가 좁으면 오른쪽 손잡이가 잘릴 수 있으므로 초점 위치와 모바일 레이아웃을 별도 확인한다. 필요 시 대사창을 이미지 위에 배치한다.
- 통합 상태: 미통합. 게임 코드 및 통합본은 수정하지 않음.

## 실제 참고 그림을 반영한 손 에셋

- 추가 요청: `assets-v5/references/coaster-lever-reference.png`와 `keeper-hand-reference.png`를 기준으로 배경과 레버가 없는 투명 손 이미지를 만들고 `neverland-v4/assets/`에 저장. UI 코드는 수정하지 않음.
- 결과: `neverland-v4/assets/keeper-coaster-hand.png` (1086×1448, 32비트 RGBA PNG). 연필 선, 흰 장갑, 손등의 별과 원형 문양을 반영했으며 위에서 손이 내려와 빈 공간을 감싸는 단일 이미지다. 네 모서리 알파 0, 손 내부 알파 254를 확인했다.
- 통합 제안: 손을 레버 손잡이 위의 별도 레이어로 배치하고 손과 레버를 함께 오른쪽으로 이동한다. 손가락 사이 빈 공간에 레버 손잡이를 배치하되, 손과 손잡이의 앞뒤 겹침은 실제 장면에서 확인하고 필요하면 레버를 나누어 렌더링한다. 상단 손목은 캔버스 경계에서 잘려 있어 화면 위쪽 밖에서 등장시키기 적합하다.
- 상태: 에셋 저장 완료, UI 미통합. 이전의 채색된 전체 화면 시안 대신 이 참고 기반 에셋을 사용하도록 제안한다. 단일 정지 이미지이므로 관절별 변형이나 프레임 애니메이션은 포함하지 않는다.
