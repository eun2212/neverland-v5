# 한국어 이름과 제작 메뉴 세분화 · 2026-11-21

요청: 확정된 영문 간판과 같은 뜻으로 한국어 놀이기구 이름을 맞추고, 장면 이동을 세밀하게 나누며 개발자 모드형 레이아웃으로 개편한다.

구현: 여섯 기구 이름을 후크의 마지막 항해, 네버랜드로의 비행, 잃어버린 아이들의 회전목마, 인어의 석호 거울, 팅커벨의 티파티, 두 번째 별 너머로 변경하고 지도·대사·조작창·저장 안내에 반영. 기존 ID·저장 구조 유지. 제작 메뉴를 스토리·놀이기구·미니게임 부스·엔딩 카드로 재구성하고 탑승·조작·키퍼 개입·운행과 꿈 선택지 및 부스 시작 등 분기를 추가했다.

검증: 전체 이야기·장면 이동·세부 장면·간판·롤러코스터 진입 자동 검사가 통과했고, 독립 검증 스레드에서 이름·저장 ID·테스트 격리 검토를 마쳤다. 실제 게임에서 메뉴 화면, 롤러코스터 키퍼 개입 후 운행, 별 맞히기 게임 진입을 확인했다. 모든 분기와 실제 기존 저장 파일 전체는 직접 확인하지 않았다.
