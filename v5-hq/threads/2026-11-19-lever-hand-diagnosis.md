# 공통 레버 손 이미지 표시 조사 — 2026-11-19

- 현재 `coaster-lever.js:17`의 기본 이미지 경로는 `assets/keeper-captain-lever-hand-v2.png`이고 파일(1,624,630바이트)이 존재한다. 캡틴 훅 첫 레버/재탑승과 롤러코스터 호출부는 handImage 옵션을 전달하지 않아 모두 이 기본 파일을 사용한다.
- 손은 처음부터 표시되지 않는다. 왼쪽 조작 또는 역방향 입력 후 조언을 3초 표시하고 `is-forcing`을 적용할 때만 CSS가 손을 표시한다. 일반 동작은 이후 약 0.74초, 움직임 감소 시 약 1.2초 후 출발 콜백에서 레버 화면이 제거된다. 오른쪽으로 바로 출발하면 손은 나타나지 않는다. 표시 구간이 짧고 장면 안 overflow:hidden으로 가장자리가 잘릴 수 있어 실제 시각 검증 필요.
- 이미지 로드 실패 시 JS가 img를 제거하며 CSS가 대체 이모지 손을 표시한다. 그러므로 이미지 로드 실패가 새 손이 보이지 않는 원인일 가능성은 있으나, 실제 요청·화면을 확인하지 못해 확정할 수 없다.
- index.html의 JS/CSS 참조에는 버전 쿼리가 없고 preview-server.cjs는 별도 Cache-Control을 지정하지 않는다. 이미 열린 탭의 오래된 스크립트나 브라우저 캐시 가능성은 있으나 확인된 원인은 아니다. 저장 자료를 지우지 않는 새로고침 후 강제 개입 동작 비교가 필요하다.
- `node verify-coaster-lever.cjs` 통과. 가상 DOM/타이머 테스트이며 이미지 픽셀의 실제 표시를 보장하지 않는다.
- 이 스레드에서 앱 내 브라우저 목록이 비어 있으며 생성 시 `Browser is not available: iab`가 반환돼 실제 게임 화면을 보지 못했다. 이미지 로드 성공·손 가시 영역·접점 및 실 사용자의 캐시 상태는 미확인이다. 코드 변경 없음.
