# 롤러코스터 탑승자와 미니게임 부스 · 2026-11-21

요청: 롤러코스터 좌석에 성별 선택에 맞는 플레이어가 탑승하도록 하고 별 맞히기·박자 맞히기 등 미니게임 부스의 외형과 간판을 게임 분위기에 어울리는 영문으로 바꾼다.

구현: 안전바 화면에 남녀 캐릭터 일러스트를 배치하고 주행 중 3D 열차에 주인공을 추가해 뒤에서 보이게 한다. GOLDEN RINGS, STAR SHOT, MEMORY MATCH, RHYTHM PARADE 간판과 각 부스별 장식을 적용한다. 타이틀의 선택이 제작용 장면 이동에도 반영되도록 수정한다.

검증: 실제 게임에서 여성 좌석, 주행 중 인물과 STAR SHOT 간판을 확인하고 남성 선택 시 남성 이미지가 로드되는 것을 확인했다. 탑승자 및 스토리·장면 이동 자동 검사를 통과했다. 캐릭터 원화 최종 수정과 독립 검증 진행 중.

최종: 남녀 모두 머리가 있고 얼굴은 가려진 착석 이미지로 갱신했다. 실제 게임에서 여자 착석과 3D 주행 중 탑승자, STAR SHOT·RHYTHM PARADE 간판을 확인했고, 남자 선택 시 남자 에셋 로딩을 확인했다. 독립 검증 스레드의 성별·기존 출발·장면 이동 검사는 통과했다. 전체 공원 장면 자동 검사는 검사 환경 오류/시간 초과로 완주하지 못했다.

사용자 수정 요청: 머리카락으로 얼굴을 가린 그림을 제거하고 남녀 자연스러운 착석 이미지 v2를 새로 제작. 좌석에 맞춰 확대하고 이미지의 얼굴이 화면 위로 벗어나도록 배치했다. 실제 여자 화면에서 표시를 확인했으며 남자 실제 화면 확인 중 게임 탭이 비정상 종료됐다. 안전바·성별·출발 자동 검사는 통과했다.

추가 수정: 사용자가 얼굴을 머리카락으로 가리는 대신 자연스러운 구도로 화면 밖에서 잘리길 요청해 남녀 v2 이미지를 별도로 연결하고 2D 장면의 인물 크기와 위치를 조정했다. HQ는 실제 여성 화면에서 얼굴 크롭과 좌석 비율을 확인했다. 남성 화면 확인 중 브라우저 탭이 종료돼 남성의 실제 화면 비율은 미확인이다. 남녀 성별 전달과 이미지 선택의 자동 검사는 통과했다. 3D 주행과 성별 분기는 유지했다.
