# 캡틴 훅 레버용 키퍼 손 재제작

- 요청: 현재 3D 키퍼와 게임 분위기에 맞는 손·소매를 새로 이미지 생성한다. 투명 PNG를 기존 에셋과 별도 저장하며 화면 코드는 수정하지 않는다.
- 조사: `neverland-v4/world.js`에서 3D 세계의 키퍼가 `assets/keeper-v3-01-basic.webp` 빌보드를 사용함을 확인하고 해당 이미지와 `ride-captain-preview.png`를 직접 확인했다. 초록 코트와 금별 장식, 아이보리 프릴, 흰 장갑 및 금·초록·붉은 조종대 색감을 반영했다.
- 결과: `neverland-v4/assets/keeper-captain-lever-hand-v2.png`, 1091×1442 RGBA PNG. 손가락 사이의 손잡이 자리 알파 0과 외부 모서리 알파 0~1을 확인했다. 기존 이미지들은 보존했다.
- 활용: 레버 손잡이를 별도 레이어로 손가락 사이에 놓고 손과 함께 가로 이동한다. 실제 UI에서 손잡이 크기·겹침과 모바일 잘림을 조정한다. 단일 정지 이미지로 손가락 관절 애니메이션은 없다.
- 상태: 시안 제작 완료, 게임 화면 미통합. 독립 요청 일치 검증 및 HQ 통합 대기.

## 독립 검증 — 2026-11-19
- 실제 게임 `world.js`가 사용하는 `assets/keeper-v3-01-basic.webp`에 대응하는 원본 이미지를 새 에셋과 직접 비교했다. 짙은 녹색 무늬 소매, 금색 별·테두리·장신구, 아이보리 프릴과 흰 장갑, 화려한 선화와 채색이 키퍼 외형과 잘 맞는다. 판단은 시각적 비교다.
- PNG는 1091×1442, 32비트 알파 채널이다. 네 모서리 알파는 1·0·0·0, 엄지와 검지 사이 예시 좌표 (540,1200)는 0, 장갑 예시 좌표 (600,1000)는 253으로 확인했다. 손과 소매는 별도 레버가 포함되지 않은 단일 이미지다.
- 손가락 사이 투명 공간이 있어 별도 손잡이와 합성할 수 있고 이미지 전체를 레버와 함께 이동할 수 있다. 다만 현재 손은 하나의 평면 레이어이므로 손잡이를 전후로 자연스럽게 감싼 것처럼 보이게 하려면 실제 크기·좌표·레이어 순서를 조정하고 확인해야 한다. 상단 소매가 이미지 경계에서 잘리므로 화면 진입 위치와 모바일 크롭도 확인이 필요하다. 손 관절 애니메이션은 없다.
- 현재 코드의 기본 손 경로는 여전히 `assets/keeper-coaster-hand.png`이고 새 v2 파일을 호출하는 참조는 확인되지 않았다. 따라서 새 에셋은 아직 실제 게임에 적용된 것으로 볼 수 없다. 화면 코드와 기존 에셋은 수정하지 않았다. 브라우저에서 레버와 실제 합성한 화면은 이번에 검증하지 않았다.
