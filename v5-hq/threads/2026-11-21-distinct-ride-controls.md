# 기구별 조작과 키퍼 손 구분 · 2026-11-21

요청: 캡틴 훅과 롤러코스터 조작, 두 회전형 기구 조작을 서로 다르게 바꾸고 각 기구의 조작에 맞는 키퍼 손을 적용한다.

결정: 캡틴 훅은 기존 수평 레버와 손 유지, 롤러코스터는 안전바를 위에서 아래로 내린다. 회전목마는 태엽을 감고, 찻잔은 주전자를 기울여 차를 따른다. 관람차는 별을 잇는다. 각 동작에 어울리는 키퍼 손 그림을 별도로 제작하고 키퍼의 강제 개입을 유지한다. 거울 미로는 유지한다.

상태: 작업별 구현과 그림 제작 진행 중. 통합 및 실제 화면 검증 예정.

최종: 기구별 손 4개, 주전자, 롤러코스터 좌석과 안전바 이미지를 생성해 연결했다. 실제 게임에서 안전바 직접 출발·강제 개입 시 두 손 배치, 주전자 직접 완료·강제 개입 시 손잡이 위치, 관람차 손 이미지를 확인했다. 직접·역방향·거부·대기·정리 및 캡틴 훅 회귀 검사가 통과했다. 독립 검증 스레드 확인 완료. 전체 3D 자동 검사는 완료되지 않았다.
